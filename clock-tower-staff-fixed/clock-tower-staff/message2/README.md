# Clock Tower — Message 2

Responsive UI modules:
- /kitchen
- /tables
- /orders
- /payments
- /manager
- /shift

This version is intentionally independent of Firebase. It provides working local interactions and responsive layouts for desktop, tablet and mobile.

Copy `src/app/*` and `src/components/operations/*` into your project.

Do not replace your existing layout, sidebar, POS, globals.css, Firebase or services.
Message 3 will connect these mock data structures to Firebase/services/hooks.
